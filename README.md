# Convite digital — 15 anos de Nathalia

Versão independente em HTML e CSS, inspirada na referência visual enviada.

## Arquivos
- `index.html` — conteúdo da página.
- `style.css` — layout, ornamentos, tipografia e animações.
- `README.md` — instruções.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e a pasta `assets` (se houver) para a raiz.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. O GitHub fornecerá um link HTTPS que abre em navegadores Android e iPhone.
